# Inventory SQL Project

## Project Overview
This project demonstrates SQL-based database management and inventory data analysis using MySQL.

## Files Included
- `products_data.xlsx` – Product inventory dataset
- `babydino.sql` – SQL database structure, data, and queries

## Tools Used
- MySQL Workbench 8.0
- SQL
- Microsoft Excel

## SQL Operations
- Database and table creation
- Data insertion
- Data filtering using WHERE
- Sorting using ORDER BY
- Category-wise analysis using GROUP BY
- Aggregate functions such as COUNT, AVG, and SUM

## Database
**Database:** babydino  
**Table:** products
